AnimalGame Strategy Engine: A turn-based strategy board game implemented in Python.

Features:
- Multiple piece types
- Custom movement rules
- Turn-based gameplay
- Piece capture mechanics
- Win condition detection
- Automated unit tests

Concepts Demonstrated:
- Object-Oriented Programming
- Inheritance
- Polymorphism
- Game State Management
- Unit Testing
